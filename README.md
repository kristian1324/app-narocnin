## Opis

Preprosta mobilna aplikacija, izdelana z Expo in React Native. Vsebuje začetni zaslon s števcem, kartico izdelka in povezavo na drugi zaslon.

## Zagon

Namesti odvisnosti:

```bash
npm install
```

Zaženi razvojni strežnik:

```bash
npx expo start
```
